System Documentation

Quant ML Pipeline

An end-to-end Quantitative Machine Learning Pipeline for high-frequency time-series financial evaluation (Binance BTC/USDT 1-minute klines).

Key Engineering Design

Strict Temporal Splitting: Chronological data partitioning ensures historical training data strictly precedes validation and testing sets, preventing lookahead bias.

Zero-Leakage Feature Engineering: Moving average distance, rolling volatility, RSI, and volume ratio indicators are computed using strict backward-looking windows to maintain data integrity.

Statistical Drift Detection: Evaluates potential distribution shifts between training baseline and test intervals using Population Stability Index (PSI) and Kolmogorov-Smirnov (KS-Test).

System Components

Model Registry & Promotion Gate: Automatically logs execution manifests, tracks random seed determinism, and evaluates candidate models against active production checkpoints.

Low-Latency Serving: FastAPI serving layer delivering sub-millisecond REST inference endpoints paired with a responsive 3D WebGL terminal interface.
